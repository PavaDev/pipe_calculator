# คำนวณระบบสุขาภิบาล

เว็บคำนวณขนาดท่อประปา ถังเก็บน้ำ และเครื่องสูบน้ำ (Hunter's Curve, Water Factor ตาราง 2.4/2.5, Hazen-Williams, Motor Sizing)
เป็นไฟล์ HTML ไฟล์เดียว ไม่ต้อง build — เปิด `index.html` ได้ทันที

## Deploy ด้วย GitHub Pages
1. Push `index.html` และ `.nojekyll` ขึ้น repository
2. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)`
3. เข้าใช้งานที่ `https://<username>.github.io/<repo>/`
